# שומר מהריגה (Kill Guard)

מודול Xposed ל-**Vector / LSPosed** שמונע מכפתור "סגור הכל" באפליקציות האחרונות, וממנקי זיכרון, להרוג אפליקציות שבחרת. השימוש העיקרי הוא לאנצ'ר חיצוני, כמו Microsoft Launcher, שנסגר ונטען מחדש בכל לחיצה על "סגור הכל".

## מה הוא חוסם

- **ריגת רקע:** `killBackgroundProcesses` ועצירה בכפייה שאפליקציה אחרת מבקשת, למשל מסך האחרונות (com.android.launcher3) או מנקה זיכרון.
- **סגירת תהליך עם הסרת כרטיס:** כשמסירים כרטיס מרשימת האחרונות, התהליך של אפליקציה מוגנת לא נסגר.
- **הריגה כללית:** הריגה של כל התהליכים שברקע.

## מה ממשיך לעבוד כרגיל

- קריסה ו-ANR.
- עדכון והסרה של אפליקציה.
- מחסור אמיתי בזיכרון (lmkd).
- עצירה בכפייה שאתה עושה בעצמך, מההגדרות או מ-adb/root.

## התקנה

1. מתקינים את ה-APK מ-[Releases](../../releases).
2. ב-Vector / LSPosed מפעילים את "שומר מהריגה". בהיקף מסמנים **מסגרת המערכת (System Framework)** ואת המודול עצמו.
3. מאתחלים את הטלפון.
4. פותחים את האפליקציה ומסמנים את האפליקציות להגנה. הלאנצ'ר שמוגדר כברירת מחדל מסומן אוטומטית בפתיחה הראשונה.

שינויים ברשימה נכנסים לתוקף מיד, בלי אתחול.

- **יומן (☰):** מראה מה נחסם ומה הותר, ולמה. כדי לקרוא אותו צריך root, ואפשר לראות אותו גם ביומן של Vector.
- **מצב קשוח:** חוסם כל הריגה של אפליקציה מוגנת, חוץ מהחריגים שלמעלה. הוא מיועד למקרים שבהם ה-ROM הורג בדרך שהמצב הרגיל לא מכיר.

## איך זה עובד

המודול רץ בתוך system_server ומתערב בכמה נקודות:

- **`ProcessList.removeProcessLocked`:** כל ההריגה מדולגת, כך שהתהליך ממשיך לחיות והרישום שלו במערכת נשאר עקבי.
- **`ProcessRecord.killLocked`:** הריגות ישירות, כמו "remove task".
- **`forceStopPackage` ו-`killBackgroundProcesses`:** ההחלטה תלויה באפליקציה שביקשה את ההריגה.
- **`ActivityTaskSupervisor.removeTask`:** כשמסירים כרטיס, `killProcess` הופך ל-false.

ההגדרות נשמרות ב-SharedPreferences שקריאות למודול (xposedsharedprefs). עם root הן נשמרות גם ב-`/data/system/killguard.conf`.

נבדק על Unihertz Jelly 2E, אנדרואיד 12, עם Vector.

## בנייה

בלי Gradle: `build.sh` (aapt2, ecj, d8, zipalign, uber-apk-signer). ה-API של Xposed נמצא כ-stubs לקומפילציה בלבד בתיקייה `stubs/`, ולא נכלל ב-APK.
